Updates from Home Assistant, and wireless ADB from the remote.

> **Harmonium is required.** This app hosts [Harmonium](https://github.com/skavan/harmonium) by
> [skavan](https://github.com/skavan), loaded from your own Home Assistant.

### New

- **Update from Home Assistant.** The remote shows up with an update entity: Home Assistant lists
  new releases (checked every 6 hours) with their notes. Press **Install**, and the remote
  downloads the release and checks its SHA-256; then confirm **Install** on the remote. The first
  time, Android asks to allow "Install unknown apps" for Harmonium Host.
- **Wireless ADB** on/off in Settings and as a Home Assistant switch, like the Blue-key toggle in
  Harmonium's Key Mapper setup. Optionally turned on whenever the app starts. While it's on, anyone
  on your network can use ADB on the remote, so turn it off when you're done.

### Updating from 1.0.0

1.0.0 has no updater yet, so install this one over it once:
`adb install -r harmonium-host-1.1.0.apk`. Settings are kept. Later releases can be installed
from Home Assistant.
