The first public release of **Harmonium Host**, a native Android app for the Sanytron Astrion
HA100 remote that runs [Harmonium](https://github.com/skavan/harmonium) full screen.

> **Harmonium is required.** This app hosts [Harmonium](https://github.com/skavan/harmonium) by
> [skavan](https://github.com/skavan), loaded from your own Home Assistant. It does nothing useful
> without it: install and set up Harmonium first.

### Why

Harmonium on the Astrion ran in Fully Kiosk Browser, with Key Mapper for the buttons. The mic
button couldn't work over plain `http://`, the first press only woke the screen, and there was no
charging feedback. Harmonium Host replaces both apps with one native shell.

### Highlights

- **Voice:** hold the mic button to talk to Home Assistant Assist. The remote is an ESPHome voice
  satellite with its own area and pipeline, the reply plays on the remote, and plain http is fine.
- **Awake when you need it:** lift-to-wake off the cradle; on the cradle the screen stays on,
  dimmed, with a clock (and optional weather) screensaver showing the battery.
- **Pull-down panel,** like the stock launcher's: Wi-Fi and Home Assistant status, brightness,
  volume, reload, stay on, and the full settings.
- **Built-in key mapping,** so Key Mapper isn't needed.
- **Charging screen** and battery readout.
- **Home Assistant device:** controls (screen, screensaver, brightness, volume), buttons (reload,
  clear cache, restart, screenshot of any app), every setting, and diagnostics.
- **Can be the home screen,** so it starts after a reboot.

### Install

Follow [Install](https://github.com/fahrer16/Harmonium_Host#install) in the README. In short:

1. Download `harmonium-host-1.0.0.apk` below.
2. Install it: `adb install harmonium-host-1.0.0.apk`.
3. Set the Home Assistant URL (by IP) and the remote profile, then save.
4. Accept the remote in Home Assistant (Devices & services → ESPHome).

If you ran a development build before, uninstall it first. This release is signed with a different
key and has its own app ID, so Home Assistant sees it as a new device: remove the old one there.

Requires Android 8.1 or newer. It's built for and tested on the Astrion HA100.
